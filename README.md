# 📋 Sobre o Projeto

O **ConectaÊ** é uma plataforma de impacto social concebida como artefato das **Práticas Extensionistas** do curso de **Sistemas de Informação do CESMAC**.

O objetivo central é **mitigar a assimetria de informação no terceiro setor**, oferecendo visibilidade para ONGs menores e facilitando o engajamento comunitário através de um **Hub centralizado**.

Esta versão utiliza o framework **Angular**, aplicando uma arquitetura baseada em **componentes e serviços** para garantir uma **Single Page Application (SPA)** performática, escalável e acessível.

---

# 🚀 Funcionalidades Principais

- **Hub Centralizado**  
  Visualização de projetos sociais e causas pouco visíveis.

- **Agenda de Eventos**  
  Mural interativo com suporte a geolocalização para otimizar a logística do voluntariado.

- **Gestão de Voluntariado**  
  Fluxo intuitivo para usuários se candidatarem e apoiarem causas locais.

- **Interação Social**  
  Sistema de engajamento através de comentários e curtidas.

# ♿ Acessibilidade (Diretrizes WCAG 2.1)

O sistema foi desenvolvido seguindo padrões de inclusão digital baseados na norma **WCAG 2.1**.

## Princípios Aplicados

- **Contraste e Legibilidade**  
  Paleta de cores (Verde Água e Branco) otimizada para usuários com baixa visão.

- **Affordance**  
  Estados de foco e interação (`hover` e `focus`) claros para auxílio em deficiências cognitivas.

- **Navegação Semântica**  
  Estrutura linear:

```

Home → Busca → Detalhes

```

Favorecendo o uso de **leitores de tela**.

- **Target Size**  
Elementos clicáveis dimensionados em **mínimo de 44x44 pixels** para usuários com mobilidade reduzida.

# 🔧 Como Executar o Projeto

## Pré-requisitos

* Node.js **v18 ou superior**
* Angular CLI

Instalação do Angular CLI:

```bash
npm install -g @angular/cli
```

---

# 📥 Instalação

Clone o repositório:

```bash
git clone https://github.com/euoluizg/ImpactaMais2.git
```

Entre na pasta do projeto:

```bash
cd ImpactaMais2
```

Instale as dependências:

```bash
npm install
```

---

# ▶️ Execução

Inicie o servidor de desenvolvimento:

```bash
ng serve
```

Abra no navegador:

```
http://localhost:4200
```
